# Техническое задание

**Проект:** Система регистрации на экскурсии «MyГид». **Заказчик:** MyГид. **Автор:** [Сартов Эржан Бекжигитович, группа 11 ТЭС-26].
**Версия документа:** 1.0. **Дата:** 19.11.2026.

## Назначение и функции

Система предназначена для менеджеров экскурсионного бюро «MyГид» для оперативной регистрации туристов на экскурсии. Основание — документ [Требования](03_Требования.md).
Обязательные функции: создание записи (FR-1), просмотр списка и карточки (FR-2), поиск и фильтрация (FR-3), смена статуса по правилам (FR-4), удаление с подтверждением (FR-5), валидация полей (FR-6).

## Интерфейс

- **Компоновка:** одно главное окно Tkinter (`980x620`), разделённое на три зоны:
  1. Верхняя панель: поле текстового поиска, выпадающий список фильтрации по статусу и кнопка «Сбросить фильтры».
  2. Центральная область: слева — таблица `ttk.Treeview` со столбцами (`№`, `Экскурсия`, `Дата`, `Турист (ФИО)`, `Телефон`, `Мест`, `Статус`); справа — панель «Карточка записи на экскурсию» с полями ввода и кнопками действий.
  3. Нижняя строка состояния: отображает количество найденных записей и напоминание о хранении данных в памяти.
- **Действия:** кнопки «Добавить новую», «Сохранить изменения», «Удалить запись», «Очистить форму».
- **Ошибки:** модальные окна `messagebox.showerror` при пустых полях, неверной дате, количестве мест вне диапазона 1–20 или нарушении графа статусов.

## Данные и реализация

- **Стек:** Python 3.11+, стандартная библиотека `tkinter` (`ttk`, `messagebox`) и модуль `datetime`.
- **Структура записи (словарь Python):**
  - `id` (`int`) — уникальный номер (генерируется автоматически, обязателен);
  - `excursion` (`str`) — название экскурсии (обязательно);
  - `date` (`str`) — дата проведения в формате `ДД.ММ.ГГГГ` (обязательно);
  - `client` (`str`) — ФИО туриста (обязательно);
  - `phone` (`str`) — контактный телефон, не менее 6 символов (обязательно);
  - `tickets` (`int`) — количество мест от 1 до 20 (обязательно);
  - `status` (`str`) — одно из значений: `Новая`, `Подтверждена`, `Завершена`, `Отменена`.
- **Хранение:** список словарей `self.bookings` в оперативной памяти. При старте загружаются 3 демонстрационные записи; при закрытии окна все изменения сбрасываются.
