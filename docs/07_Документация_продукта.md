## Назначение

Приложение **«MyГид»** предназначено для менеджеров экскурсионного бюро. Оно позволяет регистрировать туристов на экскурсии, отслеживать статусы бронирования, быстро находить нужные заявки во время звонка клиента и предотвращать ошибки ввода.

## Установка и запуск

1. **Системные требования:** ОС Windows 10/11, Linux или macOS; установленный **Python 3.11 или новее** с модулем `tkinter`.
2. **Получение файлов:** скачайте архив репозитория с GitHub и распакуйте в любую папку (например, `C:\Projects\mygid`).
3. **Запуск:** откройте терминал в корневой папке проекта и выполните команду:
   ```bash
   python src/main.py
   ```
   Установка дополнительных библиотек через `pip` не требуется.
4. **Демонстрационные данные:** сразу после запуска в таблице уже присутствуют 3 вымышленные записи (Иванов А.П., Смирнова Е.В., Козлов Д.С.) для мгновенной проверки работы.

## Основные сценарии

- **Добавить запись на экскурсию:** нажмите кнопку «Очистить форму» (если выбрана существующая строка), заполните все 5 обязательных полей справа (например, экскурсия *«Ночной Петербург»*, дата *«28.11.2026»*, ФИО *«Петров Иван Иванович»*, телефон *«+79112223344»*, мест *«2»*) и нажмите **«Добавить новую»**. Новая строка появится в таблице со статусом `Новая`.
- **Найти запись:** введите в верхнее поле «Поиск» часть фамилии, номер записи или название экскурсии — таблица обновится автоматически. Для отбора по состоянию заявки выберите нужный пункт в списке «Статус».
- **Изменить данные или статус:** кликните по нужной строке в таблице слева, отредактируйте поля в карточке справа или выберите новый статус и нажмите **«Сохранить изменения»**.
  - *Правила статусов:* из `Новая` можно перейти в `Подтверждена` или `Отменена`; из `Подтверждена` — в `Завершена` или `Отменена`. Статусы `Завершена` и `Отменена` являются окончательными.
- **Удалить запись:** выберите строку в таблице, нажмите **«Удалить запись»** и подтвердите действие нажатием «Да» во всплывающем окне.
- **Завершить работу:** закройте окно приложения крестиком в правом верхнем углу. **Внимание:** в версии v1.0 данные хранятся только в оперативной памяти, поэтому после закрытия окна все внесённые изменения сбрасываются.

## Частые вопросы

- **Запись не добавляется, появляется окно с ошибкой.** Проверьте, что заполнены все 5 полей со звёздочкой `*`, дата введена строго в формате `ДД.ММ.ГГГГ` (например, `25.11.2026`), а количество мест указано числом от `1` до `20`.
- **В таблице пусто / ничего не найдено.** Нажмите кнопку **«Сбросить фильтры»** на верхней панели, чтобы очистить строку поиска и вернуть фильтр статуса в положение `Все`.
- **Почему после закрытия программы исчезли добавленные записи?** По условиям первой версии приложение работает без базы данных и не записывает файлы на диск.
